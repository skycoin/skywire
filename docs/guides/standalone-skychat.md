# Standalone skychat

This page moved. The maintained guide, covering TCP-direct, CXO, persisted
history and a verified two-instance walkthrough, is
[skychat/standalone-skychat.md](../skychat/standalone-skychat.md).

The one correction worth repeating from the old copy of this page: an
empty `--tcp-whitelist` does not reject connections. It accepts any
authenticated key, matching the skynet and CXO convention. Set it to pin
specific peers.
