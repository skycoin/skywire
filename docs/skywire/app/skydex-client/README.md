## Flags

```

      --market-pk string       default skydex-market public key (pre-filled in the UI; not auto-connected)
      --market-port uint16     market dmsg routing port to dial (must match the market's --port) (default 8050)
      --password-file string   file holding the trading UI's basic-auth credential (empty = ungated)
      --port uint16            routing port for communication between app and visor
```
