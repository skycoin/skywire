# skywire cli rewards run

[← skywire cli rewards](../README.md)

Performs the entire hourly reward cycle:

  1. Collect surveys (skywire cli log --survey --cleanup)
  2. Collect transport counts (skywire cli rewards tp-collect)
  3. Collect bandwidth data (skywire cli rewards bw-collect)
  4. Fetch uptime tracker data, prune to single day
  5. Calculate rewards
  6. Write hist/{date}_{ut.txt,ut.json,ineligible.csv,shares.csv,rewardtxn0.csv,stats.txt}

Designed to be invoked directly by systemd:

  ExecStart=/usr/bin/skywire cli rewards run

Replaces the legacy 'script reward | bash' pipeline.

## Usage

```
skywire cli rewards run
```

## Flags

```
  -d, --date string    date to calculate (YYYY-MM-DD); default = yesterday UTC
  -H, --hist string    history output directory (default "hist")
  -p, --lpath string   path to collected surveys (default "log_backups")
      --minv string    minimum skywire version to fetch from / keep surveys for
      --skip-collect   skip survey/tp/bw collection (use existing data on disk)
```

## Global Flags

```
      --json   print output as JSON
```
