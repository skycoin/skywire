# skywire cli contacts

[← skywire cli](../README.md)

The visor's address book: the people its operator knows, with the skywire
keys, mail and payment addresses that reach them. Each contact is a vCard
4.0 file beside the visor's local directory, so the book imports from and
exports to any address book. Nothing in it is published. A contact is named
by its UID or its name. Bare `contacts` lists the book.

## Usage

```
skywire cli contacts
```

## Subcommands

- [add](add/README.md) — Add a contact
- [export](export/README.md) — Write the whole book as one .vcf file
- [import](import/README.md) — Add every card of a .vcf file, replacing contacts with the same UID
- [ls](ls/README.md) — List the contacts
- [rm](rm/README.md) — Remove a contact
- [set](set/README.md) — Change a contact: each flag given replaces that field
- [show](show/README.md) — Show one contact

## Examples

```
skywire cli contacts add Alice --key 02a4... --pay skycoin:2jBbGx --group friends
  skywire cli contacts set Alice --mail alice@example.com
  skywire cli contacts export -o contacts.vcf
  skywire cli contacts import phone.vcf
```
