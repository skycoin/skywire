# skywire cli visor cxo feeds add

[← skywire cli visor cxo feeds](../README.md)

Spin up a CXO TreeStore publisher under the visor's PK on the
given DMSG port. The port must be unused by other feeds and not
collide with reserved DMSG ports (e.g. 46 hypervisor, 47 transport
setup, 50 system telemetry).

## Usage

```
skywire cli visor cxo feeds add <name> <dmsg-port>
```
