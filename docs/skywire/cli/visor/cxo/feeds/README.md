# skywire cli visor cxo feeds

[← skywire cli visor cxo](../README.md)

Each visor publishes a single system feed (telemetry) by default.
User feeds are independent CXO TreeStore publishers running on
distinct DMSG ports under the same visor PK. Subscribers fetch
http://<visor-pk>.dmsg/feeds for the catalog, then connect to the
desired (PK, dmsg_port) pair over DMSG.

## Usage

```
skywire cli visor cxo feeds
```

## Subcommands

- [add](add/README.md) — Register a new CXO user feed
- [ls](ls/README.md) — List published CXO feeds (system + user)
- [rm](rm/README.md) — Stop and remove a CXO user feed

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --rpc string        RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
