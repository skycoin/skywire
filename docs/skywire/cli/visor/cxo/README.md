# skywire cli visor cxo

[← skywire cli visor](../README.md)

Inspect and manage user-published CXO feeds running on the visor.

## Usage

```
skywire cli visor cxo
```

## Subcommands

- [feeds](feeds/README.md) — List, add, and remove CXO user feeds
- [fetch](fetch/README.md) — Call FetchCXO for a (feed, path) pair and dump the result
- [refresh](refresh/README.md) — Force a synchronous subscribe + first-Root + walk for one (or all) feeds
- [status](status/README.md) — Show per-feed snapshot + last-sync + last-error

## Global Flags

```
      --json         print output as JSON
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
