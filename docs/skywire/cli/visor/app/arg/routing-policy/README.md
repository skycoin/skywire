# skywire cli visor app arg routing-policy

[← skywire cli visor app arg](../README.md)

Install or replace an app's per-dial routing policy on a RUNNING app
  without restarting it — the route-selection hook is swapped live.

  <policy> accepts:
    preset:<name>   a built-in preset (see 'route policy list')
    @/path.star     a Starlark policy file (hot-reloaded on change)
    @/path.wasm     a compiled WASM policy file (hot-reloaded on change)
    "" or "none"     clear any previously-installed override

## Usage

```
skywire cli visor app arg routing-policy <name> <policy>
```
