# skywire cli visor app arg whitelist

[← skywire cli visor app arg](../README.md)

Set the comma-separated public-key whitelist that gates incoming
connections to skysocks or vpn-server. Empty / "remove" / "none"
clears the whitelist (open to all authenticated peers).

## Usage

```
skywire cli visor app arg whitelist <name> <pks>
```
