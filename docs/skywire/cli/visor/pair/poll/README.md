# skywire cli visor pair poll

[← skywire cli visor pair](../README.md)

Pull every inbound pair message buffered on the visor with TS
strictly after --since (or the full inbox window when --since is empty).

The visor keeps a bounded ring (1024 messages by default); poll often
enough that it doesn't roll over between reads.

## Usage

```
skywire cli visor pair poll
```

## Flags

```
      --since string   only report messages with TS strictly after this RFC3339 timestamp; empty drains the full window
```

## Global Flags

```
      --json         print output as JSON
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
