# skywire cli visor pair delete

[← skywire cli visor pair](../README.md)

Delete for everyone: publish a retraction naming a message this
visor sent earlier, identified by the id that "pair send" printed. The
retraction rides the same feed, so an offline peer applies it when it
next syncs.

## Usage

```
skywire cli visor pair delete <peer-pk> <message-id>
```
