# skywire cli visor pair add

[← skywire cli visor pair](../README.md)

Open a chat-pair publisher (allowlist=[peer-pk]) and a subscriber
to the peer's matching publisher. The peer must call `pair add` with
this visor's PK on its side for the connection to actually flow.

## Usage

```
skywire cli visor pair add <peer-pk>
```

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --rpc string        RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
