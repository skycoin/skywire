# skywire cli visor hostbridge

[← skywire cli visor](../README.md)

Use the sockets of a host bridge.

A visor in a browser tab cannot listen on a port of its host. A host bridge,
started on that host with 'skywire hostbridge', listens for it. Connect the
visor to the URL the bridge prints, then forward host ports to addresses
the visor can dial, such as the local port of skysocks-client.

A computer without skywire can get the bridge from a browser visor: open
/hostbridge/ on its dashboard (the "host bridge" app in the desk). It offers
the build for the computer and shows the command to run it. The guide is
docs/guides/host-bridge.md.

## Usage

```
skywire cli visor hostbridge
```

## Subcommands

- [connect](connect/README.md) — Connect to the host bridge at the URL it printed
- [disconnect](disconnect/README.md) — End the session to the host bridge and its forwards
- [forward](forward/README.md) — Listen on a port of the bridge's host and pass connections to a local address
- [status](status/README.md) — Show the session to the host bridge and its forwards
- [unforward](unforward/README.md) — Stop a forward, named by the host address it was asked for
