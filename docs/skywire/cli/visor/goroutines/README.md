# skywire cli visor goroutines

[← skywire cli visor](../README.md)

Fetch http://<pprof-addr>/debug/pprof/goroutine?debug=2 and either
print a human summary (default) or the raw dump (--full).

Use when the visor RPC is hung or unresponsive — the pprof port stays
serving even when the rpc.Server is stuck behind a mutex, so this is
the most reliable way to see what's actually blocked.

Examples:

  skywire cli visor goroutines
  skywire cli visor goroutines --state RWMutex.RLock
  skywire cli visor goroutines --filter transport.\(.Manager\) --full
  skywire cli visor goroutines --out /tmp/visor-grs.txt --full
  skywire cli visor goroutines --top 25

## Usage

```
skywire cli visor goroutines
```

## Flags

```
      --filter string       regex matched against stack body; only matching goroutines are printed in --full mode and counted in summary
  -F, --full                print the raw pprof text instead of the summary
      --locks               in summary mode, run the lock-waiter analysis (set --locks=false to skip) (default true)
  -o, --out string          save raw dump to this file (in addition to stdout output)
      --pprof-addr string   visor pprof HTTP address (default matches --pprofaddr's default) (default "localhost:6060")
      --state string        filter by goroutine state substring, e.g. 'RWMutex.RLock' / 'IO wait' / 'select'
  -n, --top int             how many top stack-head buckets to show in summary (default 10)
```

## Global Flags

```
      --timeout int   RPC timeout in seconds (0 = unlimited) (default 30)
```
