# skywire cli visor services

[← skywire cli visor](../README.md)

List the deployment services this visor runs in its own process, from
config.embedded_services. A service under its own key can be stopped,
started and restarted on its own; a mounted one runs with the visor.

## Usage

```
skywire cli visor services
```

## Subcommands

- [restart](restart/README.md) — Restart an embedded service that runs under its own key
- [start](start/README.md) — Start an embedded service that runs under its own key
- [stop](stop/README.md) — Stop an embedded service that runs under its own key
