# skywire cli visor hv apps

[← skywire cli visor hv](../README.md)

List the apps of every visor this hypervisor manages, including visors
reached through a sub-hypervisor. The start, stop and add subcommands act on
the visors named by --pks, or on all of them with --all. One failing visor
does not stop the others, and each visor's result is printed.

## Usage

```
skywire cli visor hv apps
```

## Subcommands

- [add](add/README.md) — Add an app from the catalog to the chosen visors
- [start](start/README.md) — Start an app on the chosen visors
- [stop](stop/README.md) — Stop an app on the chosen visors

## Flags

```
      --app string   only visors running this app
```
