# skywire cli visor hv apps add

[← skywire cli visor hv apps](../README.md)

Add an app entry to each chosen visor. The binary defaults to the name,
so "add skysocks-client" adds the catalog app of that name.

## Usage

```
skywire cli visor hv apps add <name> [binary]
```

## Flags

```
      --all          every visor this hypervisor manages
      --pks string   comma separated visor public keys
      --start        start the app after adding it
```
