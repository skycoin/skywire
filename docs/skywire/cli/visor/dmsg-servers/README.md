# skywire cli visor dmsg-servers

[← skywire cli visor](../README.md)

List of connected DMSG servers sorted by latency (lowest first)

## Usage

```
skywire cli visor dmsg-servers
```

## Flags

```
  -L, --live   live-refresh mode (bubbletea TUI, 1s tick); shows DMSG server latencies updating in place
```

## Global Flags

```
      --json         print output as JSON
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
