# skywire cli hv gen

[← skywire cli hv](../README.md)

Generate a self-contained, serverless hypervisor.html.

The output is a single file (Angular UI + WASM dmsg client + override.js + your
config, all inlined) you can open from file:// — no server. By default it is a
STANDALONE hypervisor (visors dial in); --viewer-pk makes it dial a remote
hypervisor instead. --visor targets a full wasm-VISOR (edge + router + its own
hypervisor, TinyGo) — pass the wasm-visor binary as --wasm plus its TinyGo
--wasm-exec; the page then runs a complete visor in the tab and serves its own
hypervisor UI.

Identity: --sk sets an explicit key; otherwise -c <config> derives a standalone
key from the visor's secret key (one-way + deterministic — regenerable, and a
compromised standalone key can't expose the parent). Use --password to encrypt
the baked-in key (the plaintext never touches the file).

SECURITY: never serve a generated (key-bearing) file from a domain — it would
train users to type secret keys into pages from external hosts.

## Usage

```
skywire cli hv gen
```

## Flags

```
  -c, --conf string        visor config to derive the standalone key from (uses its sk)
      --disc string        dmsg discovery (dmsg://<pk>:80)
      --index uint32       with -c: re-derive keyring entry at this index (read-only); omit to mint+record the next one
  -o, --out string         output file (default "hypervisor.html")
      --password string    encrypt the baked-in key with this password (recommended)
      --seed-pk string     seed dmsg server PK the browser connects to first
      --seed-ws string     seed dmsg server ws:// URL
      --sk string          explicit standalone secret key (hex) — skips derivation
      --viewer-pk string   viewer mode: dial this remote hypervisor PK (default: standalone — visors dial in)
      --visor              target a full wasm-VISOR (cmd/wasm-visor, TinyGo) — edge + router + its own hypervisor — instead of the standalone dmsg-client hypervisor
      --wasm string        path to the wasm binary: the js/wasm dmsg-client (make dmsg-wasm), or the TinyGo wasm-visor with --visor [required]
      --wasm-exec string   path to wasm_exec.js (REQUIRED with --visor: TinyGo's differs from Go's; build/wasm-visor/wasm_exec_tinygo.js)
```

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
