# skywire cli proxy tunnel

[← skywire cli proxy](../README.md)

Operate on one TUNNEL — one route group an app holds to its exit — rather than
on the legs inside one ('proxy mux').

## Usage

```
skywire cli proxy tunnel
```

## Subcommands

- [rm](rm/README.md) — Close one of an app's tunnels and let its pool replace it
