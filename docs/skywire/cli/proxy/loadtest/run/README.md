# skywire cli proxy loadtest run

[← skywire cli proxy loadtest](../README.md)

Drive a steady stream through a proxy session and record exact goodput + gaps as NDJSON

## Usage

```
skywire cli proxy loadtest run
```

## Flags

```
  -d, --duration duration    how long to pull (default 5m0s)
  -n, --name string          proxy session name (informational)
  -o, --output string        NDJSON sink ('-' = stdout) (default "-")
      --read-kb int          read buffer size in KB (default 128)
      --slice duration       per-sample accounting slice (a zero-byte slice is a gap) (default 500ms)
      --socks string         SOCKS5 address of the proxy session to drive load through (default ":1080")
  -u, --url loadtest serve   URL of a loadtest serve endless source, reachable from the proxy exit (required)
```

## Global Flags

```
  -h, --help              show help menu
      --jq string         filter JSON output through a jq/gojq expression (implies --json)
      --json              print output as JSON
      --rpc string        RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
      --shape             print the output schema skeleton (zero values, all fields) instead of data
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --tui               browse commands and help interactively
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
