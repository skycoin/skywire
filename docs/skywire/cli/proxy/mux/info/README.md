# skywire cli proxy mux info

[← skywire cli proxy mux](../README.md)

Show per-mux-leg traffic for active route groups belonging to a named app.

Each row is one route within a mux'd route group. Sent/recv counts
are rg-scoped (only what this rg pushed through this leg) — distinct
from the transport-level totals 'tp ls' shows, which span all rg's
on that transport.

The query is local to this visor; what you see is your visor's view
of what it sent/received on each leg, not the peer's view.

Examples:
  skywire cli proxy mux info                    # one snapshot, default app
  skywire cli proxy mux info --watch 1s         # refresh every second
  skywire cli proxy mux info -n vpn-client      # query a different app
  skywire cli proxy mux info --json             # machine-readable

## Usage

```
skywire cli proxy mux info
```

## Flags

```
      --duration duration   with --ndjson: stop after this long (0 = until ctrl+c)
  -n, --name string         app name to query (e.g. skysocks-client, vpn-client) (default "skysocks-client")
      --ndjson string       per-leg telemetry harness: stream NDJSON samples + lifecycle events to FILE ('-' for stdout); interval = --watch (default 1s)
  -v, --verbose             show full PKs / transport IDs (default: short hex prefixes)
  -w, --watch duration      refresh interval; 0 prints once and exits (e.g. 1s, 500ms)
```
