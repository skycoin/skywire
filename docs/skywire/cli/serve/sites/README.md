# skywire cli serve sites

[← skywire cli serve](../README.md)

The landing page and GET /.skywire/sites, which home.skynet reads, list the
sites this visor serves on port 80: its vhosts, and for a * vhost or port 80
website handed to a local Caddy, the sites Caddy reports. `sites off` lists
none of them. The sites are still served. Bare `sites` shows the setting.

## Usage

```
skywire cli serve sites [on|off]
```

## Examples

```
serve sites        # is the list shown?
  serve sites off    # hide it
  serve sites on     # show it again
```
