# skywire cli config identity

[← skywire cli config](../README.md)

Read or replace the identity in a config file — the pk/sk pair that
makes a visor the same visor across restarts. 'export' prints them;
'import --sk' installs a secret key (and the public key derived from
it). A running visor picks the change up on its next start.

## Usage

```
skywire cli config identity
```

## Subcommands

- [export](export/README.md) — Print the config file's public and secret key as JSON
- [import](import/README.md) — Install a secret key (and its public key) into the config file

## Flags

```
  -i, --input string   config file (default: this install's config path)
```
