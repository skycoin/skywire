# skywire cli tp auto

[← skywire cli tp](../README.md)

Start or stop public autoconnect

	skywire cli tp auto      - show status
	skywire cli tp auto on   - start autoconnect
	skywire cli tp auto off  - stop autoconnect

## Usage

```
skywire cli tp auto [on|off]
```
