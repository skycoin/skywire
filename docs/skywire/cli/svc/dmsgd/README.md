# skywire cli svc dmsgd

[← skywire cli svc](../README.md)

Query DMSG Discovery service endpoints

## Usage

```
skywire cli svc dmsgd
```

## Subcommands

- [all-servers](all-servers/README.md) — List all DMSG servers
- [clients](clients/README.md) — List clients for a specific DMSG server
- [server-clients](server-clients/README.md) — List all clients grouped by server

## Flags

```
      --direct       query directly instead of via visor RPC
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```

## Global Flags

```
  -h, --help          show help menu
      --json          print output as JSON
      --timeout int   RPC timeout in seconds (0 = unlimited) (default 30)
```
