# skywire cli svc tpd bandwidth

[← skywire cli svc tpd](../README.md)

Bandwidth data from TPD. With no --pk: the network-wide /metric rollup.
With --pk <visor-pk>: that visor's /bandwidth/visor/<pk> history.

## Usage

```
skywire cli svc tpd bandwidth
```

## Flags

```
  -p, --pk string   visor public key (omit for network-wide)
```
