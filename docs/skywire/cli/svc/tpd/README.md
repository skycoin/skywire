# skywire cli svc tpd

[← skywire cli svc](../README.md)

Query Transport Discovery service endpoints

## Usage

```
skywire cli svc tpd
```

## Subcommands

- [bandwidth](bandwidth/README.md) — Bandwidth data (network-wide or per-visor)
- [bandwidth-tp](bandwidth-tp/README.md) — Bandwidth history for a specific transport
- [metrics-tp](metrics-tp/README.md) — Metrics for specific transport(s)
- [metrics-visor](metrics-visor/README.md) — Metrics for specific visor(s)
- [per-key-stats](per-key-stats/README.md) — Per-visor transport statistics
- [stats](stats/README.md) — Network-wide transport statistics
- [uptime](uptime/README.md) — TPD session history (version-tagged, with restart-loop / down-window detection)
- [versions](versions/README.md) — Version statistics from transport discovery
- [versions-pk](versions-pk/README.md) — Version info for specific public keys
- [visor-stats](visor-stats/README.md) — Transport count statistics for a specific visor

## Flags

```
      --direct       query directly instead of via visor RPC
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
