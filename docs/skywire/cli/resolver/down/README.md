# skywire cli resolver down

[← skywire cli resolver](../README.md)

Disable both resolvers. Use --dmsg-only or --skynet-only to
turn off just one.

## Usage

```
skywire cli resolver down
```

## Flags

```
      --dmsg-only     only disable the .dmsg resolver
      --skynet-only   only disable the .skynet resolver
```
