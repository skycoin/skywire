# skywire cli route groups

[← skywire cli route](../README.md)

List active route groups with their descriptor, rule IDs, and
the role this visor played in setup (initiator = we dialed, responder =
we accepted). Use --hops to also print the full forward path.

## Usage

```
skywire cli route groups
```

## Flags

```
      --filter string   role filter: all | initiator | responder (default "all")
      --hops            also print the full hop path for each route group
  -L, --live            live-refresh mode (bubbletea TUI, 1s tick); shows route groups created/torn down in place
```

## Global Flags

```
      --json         print output as JSON
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
