# skywire cli route add

[← skywire cli route](../README.md)

Add routing rule

## Usage

```
skywire cli route add ( app | fwd | intfwd )
```

## Subcommands

- [app](app/README.md) — Add app/consume routing rule
- [fwd](fwd/README.md) — Add forward routing rule
- [intfwd](intfwd/README.md) — Add intermediary forward routing rule

## Flags

```
  -a, --keep-alive duration   timeout for rule expiration (default 10m0s)
```

## Global Flags

```
      --json         print output as JSON
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
