# skywire cli log reward

[← skywire cli log](../README.md)

Fetch /reward.txt from one visor over dmsghttp. The file only
exists when the operator has set a reward address; absent files
return 404.

Gated by the remote visor's survey_whitelist.

## Usage

```
skywire cli log reward <pk>
```
