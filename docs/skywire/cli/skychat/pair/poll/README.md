# skywire cli skychat pair poll

[← skywire cli skychat pair](../README.md)

Polls the visor's PairPoll RPC and prints any messages newer than --since (default: all that are still in the inbox).

## Usage

```
skywire cli skychat pair poll
```

## Flags

```
      --limit int      max messages (1-1000) (default 100)
      --since string   RFC3339 lower bound; empty drains everything new
```

## Global Flags

```
      --addr string       skychat HTTP address (default "127.0.0.1:8001")
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
