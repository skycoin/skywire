# skywire cli skychat voice ringback

[← skywire cli skychat voice](../README.md)

The tone callers hear while this visor rings

## Usage

```
skywire cli skychat voice ringback
```

## Subcommands

- [clear](clear/README.md) — Clear the ringback tone — callers hear the plain ring again
- [set](set/README.md) — Set the ringback tone from an audio file (mp3, ogg/opus, webm, wav, m4a, aac, flac; up to 1 MB)
- [show](show/README.md) — Show the ringback tone this visor plays to its callers
