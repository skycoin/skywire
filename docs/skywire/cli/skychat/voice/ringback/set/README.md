# skywire cli skychat voice ringback set

[← skywire cli skychat voice ringback](../README.md)

Set the ringback tone from an audio file (mp3, ogg/opus, webm, wav, m4a, aac, flac; up to 1 MB)

## Usage

```
skywire cli skychat voice ringback set <audio-file>
```

## Flags

```
      --type string   audio type of the file (default: from its extension)
```
