# skywire cli version

[← skywire cli](../README.md)

Show the local build (version/commit/date) and, unless --local, resolve the
latest available release and the rolling-release branch tip the way the Go
toolchain resolves '@latest' — via the Go module proxy.

## Usage

```
skywire cli version
```

## Flags

```
  -b, --branch string            rolling-release branch to resolve the latest commit of (default "develop")
      --check-timeout duration   timeout for the latest-version resolution (default 20s)
  -l, --local                    only print the local build, skip the network check
  -m, --module string            Go module path to resolve (default "github.com/skycoin/skywire")
      --proxy string             GOPROXY base URL override (default: $GOPROXY, else proxy.golang.org)
```

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
