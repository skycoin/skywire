# skywire cli dmsg sub server

[← skywire cli dmsg sub](../README.md)

Accept dmsg streams, unframe, forward as UDP to a local target

## Usage

```
skywire cli dmsg sub server
```

## Flags

```
      --dmsg-disc string   dmsg discovery URL (defaults to deployment.Prod.DmsgDiscovery)
      --dmsg-port uint16   dmsg port to listen on (required)
      --idle duration      per-stream UDP-socket idle timeout (default 1m0s)
      --log-level string   log level: debug|info|warn|error (default "info")
      --sk string          secret key hex (env: SKYUDP_SK). Empty + no --sk-file → ephemeral keypair
      --sk-file string     path to a file containing the secret key hex (newline-trimmed)
      --target string      local UDP target the unframed datagrams are forwarded to (required, e.g. 127.0.0.1:53)
```

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
