## Flags

```
      --addr string          local SMTP listen address (Postfix transport_map target) (default "127.0.0.1:1025")

      --helo string          HELO/EHLO name presented to the peer's Postfix (default "skymail-bridge.local")
      --log-level string     log level: debug|info|warn|error (default "info")
      --mode string          envelope mode — a: verbatim; b: strip .<pk><suffix> when the recipient is host-prefixed, forward verbatim when bare-PK (strict superset of a) (default "b")
      --remote-port uint16   dmsg port to dial on the peer (where its Postfix smtpd is exposed) (default 25)
      --sk string            secret key hex (env: SKYMAIL_SK). When empty + no --sk-file, an ephemeral key is generated
      --sk-file string       path to a file containing the secret key hex (newline-trimmed)
      --suffix string        TLD suffix routed over dmsg (default ".skynet")
```
