# skywire cli dmsg pty

[← skywire cli dmsg](../README.md)

Commands for interacting with remote visors via dmsgpty

## Usage

```
skywire cli dmsg pty
```

## Subcommands

- [exec](exec/README.md) — Run a one-shot command on a remote visor (no TTY)
- [list](list/README.md) — List connected visors
- [start](start/README.md) — Start dmsgpty session
- [ui](ui/README.md) — Open dmsgpty UI in default browser
- [url](url/README.md) — Show dmsgpty UI URL

## Global Flags

```
  -h, --help              show help menu
      --json              print output as JSON
      --timeout int       RPC timeout in seconds (0 = unlimited) (default 30)
      --via dmsg://<pk>   remote visor target — dmsg://<pk> or `skynet://<pk>`
```
