# skywire cli dmsg diag

[← skywire cli dmsg](../README.md)

Inspect and manage the visor's DMSG subsystem at runtime.

## Usage

```
skywire cli dmsg diag
```

## Subcommands

- [porter](porter/README.md) — Show ephemeral port reservation counts
- [porter-diag](porter-diag/README.md) — Detailed diagnostic of RSN ephemeral port entries
- [porter-reset](porter-reset/README.md) — Free all ephemeral port reservations (recover from exhaustion)
- [reconnect](reconnect/README.md) — Force close and reconnect all DMSG sessions
