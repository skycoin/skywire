# skywire cli tps

[← skywire cli](../README.md)

Commands to control the embedded Transport Setup Node (TPS).

The embedded TPS allows this visor to manage transports on other visors
that trust this visor's TPS public key.

To enable embedded TPS, set 'tps_sk' in the visor config.

## Usage

```
skywire cli tps
```

## Subcommands

- [add](add/README.md) — Add transport on target visor
- [list](list/README.md) — List transports on target visor
- [rm](rm/README.md) — Remove transport on target visor

## Flags

```
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```

## Global Flags

```
      --json   print output as JSON
```
