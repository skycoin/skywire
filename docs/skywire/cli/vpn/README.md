# skywire cli vpn

[← skywire cli](../README.md)

VPN client

## Usage

```
skywire cli vpn
```

## Subcommands

- [list](list/README.md) — List servers
- [server](server/README.md) — VPN server control
- [start](start/README.md) — Start the VPN for a remote server
- [status](status/README.md) — VPN client status
- [stop](stop/README.md) — Stop the vpn client
- [ui](ui/README.md) — Open VPN UI in default browser
- [url](url/README.md) — Show VPN UI URL

## Flags

```
      --rpc string   RPC server address (env: SKYWIRE_RPC) (default "localhost:3435")
```
