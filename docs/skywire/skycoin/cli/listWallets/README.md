# skywire skycoin cli listWallets

[← skywire skycoin cli](../README.md)

Lists all wallets stored in the wallet directory.

    The [wallet dir] argument is optional. If not provided, defaults to $DATA_DIR/wallets

## Usage

```
skywire skycoin cli listWallets
```
