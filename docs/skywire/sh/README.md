# skywire sh

[← skywire](../README.md)

skywire sh with no arguments is an interactive websh on this terminal: the
shell, applets and line editor of the browser desk, on this machine's files
and programs. skywire in it runs in this process, as it does in a desk, so it
needs no binary of its own. With -c it runs a command line, with FILE a script,
and with its input not a terminal, the script it reads.

## Usage

```
skywire sh [FILE [ARG...]] [flags]
```

## Flags

```
  -c, --command string   run this command line, then exit
  -l, --login            accepted for login shells; websh reads no profile
```

## Global Flags

```
  -h, --help        show help menu
      --jq string   filter JSON output through a jq/gojq expression (implies --json)
      --json        print output as JSON
      --shape       print the output schema skeleton (zero values, all fields) instead of data
      --tui         browse commands and help interactively
```
