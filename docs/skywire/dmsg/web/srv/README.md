# skywire dmsg web srv

[← skywire dmsg web](../README.md)

DMSG web server - tunnel a local TCP port over DMSG. Bytes flow
transparently, so HTTP, WebSockets, and any other TCP-based protocol
the local service speaks all work unchanged.
	.conf file may also be specified with DMSGWEBSRV=/path/to/dmsgwebsrv.conf skywire dmsg web srv

## Usage

```
skywire dmsg web srv
```
