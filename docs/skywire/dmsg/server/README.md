```
DMSG Server - relays DMSG traffic between clients.

HTTP Endpoints:
  GET  /health     Health check

Example:
  skywire dmsg server config gen -o dmsg-config.json
  skywire dmsg server start dmsg-config.json
```

## Usage

```
skywire dmsg server
```
