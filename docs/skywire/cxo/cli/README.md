# skywire cxo cli

[← skywire cxo](../README.md)

CXO CLI client for interacting with a running CXO daemon via RPC.

## Usage

```
skywire cxo cli
```

## Subcommands

- [connection](connection/README.md) — Connection management commands
- [feed](feed/README.md) — Feed management commands
- [root](root/README.md) — Root object commands
- [stat](stat/README.md) — Show node statistics
- [stop](stop/README.md) — Stop the CXO daemon
- [tcp](tcp/README.md) — TCP transport commands
- [udp](udp/README.md) — UDP transport commands

## Flags

```
  -a, --address string   RPC address to connect to (default "[::]:8871")
  -e, --exec string      execute command and exit
```

## Global Flags

```
  -h, --help   show help menu
```
