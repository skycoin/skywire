## Usage

```
skywire cxo cli udp
```

## Subcommands

- [connect](connect/README.md) — Connect to a UDP address
- [disconnect](disconnect/README.md) — Disconnect from a UDP address
- [subscribe](subscribe/README.md) — Subscribe to a feed via UDP connection
- [unsubscribe](unsubscribe/README.md) — Unsubscribe from a feed via UDP connection
