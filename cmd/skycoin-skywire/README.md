# skycoin-skywire

Combined binary integrating Skywire networking with Skycoin wallet and
blockchain tools.

The command-line surface is a superset of `skywire`. See the generated
docs at [/docs/skywire/README.md](../../docs/skywire/README.md) — every
`skywire <cmd>` page applies to `skycoin-skywire <cmd>` as well.

Skycoin-specific subcommands are under
[/docs/skywire/cli/skycoin/README.md](../../docs/skywire/cli/skycoin/README.md).

Run `skywire doc` from the repo root to regenerate the docs tree.
