# skywire

Command-line documentation for the `skywire` binary lives at
[/docs/skywire/README.md](../../docs/skywire/README.md).

That tree is generated from the live cobra command structure — one
markdown file per command, mirroring the subcommand hierarchy. Run the
hidden `skywire doc` subcommand from the repo root to regenerate it
after adding, removing, or renaming any command:

```
skywire doc
```
