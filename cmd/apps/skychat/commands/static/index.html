                New Channel

                Anyone with the address or invite link can join and read. Only admins can post — members cannot reply on the channel itself. Messages are not encrypted on the feed: admission is open, so the key would go to anyone who asked and would protect nothing. Traffic is still encrypted in transit.

                History and files are served by the channel's admins, not by other subscribers — a subscriber has nothing of its own to share, so a large channel stays cheap to follow. New joiners receive the backlog in chunks while an admin is online.

                On means anyone who knows this visor's public key can discover this channel by asking it. Off keeps it reachable only by its address or an invite link. An admin can change this later.

                Group members

                On means anyone holding this visor's public key can discover it by asking. Off keeps it reachable only by address or invite link. Other admins publish their own copies independently.

                Cost to ask to join
                Anyone can make unlimited public keys, so a flood of join requests costs an attacker nothing and costs you your attention. This makes each request spend CPU first — unnoticeable once, expensive by the thousand. Raise it while you are being flooded. Requests are also rate-limited and the approval queue is capped regardless.
                Off means only admins can, so nothing reaches a new member — and no message passes between two non-admins — while every admin is offline. On, each member keeps a copy of the room; only members can read it either way.
                Membership, moderation and files are encrypted
                Joins, removals, promotions, bans and mutes travel sealed under the group key, exactly like the messages — so someone who can pull this group's feed without being in it cannot read who was banned, who was muted, or when. Key hand-offs no longer name who they are addressed to either. Shared files are sealed under the same key before they leave this device and stay sealed on every member's disk, so a copy of the downloads folder — or a re-send to someone outside the group — is bytes nobody can open. Such an observer can still tell that an admin acted, roughly when, how many members the group has, and the name and size of a file. Members still running an older build publish these changes in the clear until they update.
                Encryption: key #0
                The key rotates on its own once it has covered a week or a few thousand messages, so no single key covers the whole life of the group. Evicting a member rotates it immediately. Rotate by hand if a member's device or key may have been exposed — the new key is sealed to each remaining member, so anyone outside the group stops being able to read new messages. Older messages stay readable. Each rotation seals with a throwaway key that is discarded on the spot, so leaking an admin's identity key later does not re-open past keys. Keys are stored encrypted on this device, tied to this visor's identity.
