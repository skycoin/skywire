# Agent skills

These are skills for AI coding agents working with skywire. Each directory holds a `SKILL.md` that covers one subsystem or one group of CLI commands, with the commands that work and the traps to avoid. They are short on purpose. The full command reference is generated by `skywire doc`, so the skills point to it and do not copy it.

Keep them generic. A skill must not name particular hosts, machines, IP addresses or public keys of particular visors, must not use absolute paths from one person's machine, and must not link to private notes. Use placeholders such as `<pk>`. Where a command prints the real value, tell the reader to run that command.

Write in plain short sentences, as AGENTS.md asks.

## The test

`go test ./cmd/skywire/commands/ -run TestSkill` reads every `SKILL.md` and checks it against the real command tree.

- Each `skywire ...` command in backticks or in a code block must resolve to a command. Commands written without the `skywire cli` prefix are checked for flags only.
- Each flag written with a command must exist on that command or on a parent that passes it down.
- Each long flag written anywhere in backticks or a code block must exist on at least one skywire command, unless the span runs another program such as `curl` or `go`.

A failure names the skill and the missing command or flag. When a command changes, fix the skill in the same change.
