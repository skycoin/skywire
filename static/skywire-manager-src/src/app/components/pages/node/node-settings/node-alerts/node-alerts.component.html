This visor mails you when a visor it watches has been offline for the delay below, and once more when it is back. A visor that returns within the delay sends nothing. It watches the visors its hypervisor manages. Changes apply at once.

When every visor behind one public IP goes down together you get one site alert instead of one per visor, and each alert says whether it looks like power, internet or a faulty board.

Email addresses
Comma separated. Empty turns mail alerts off.
Offline delay
How long a visor must stay offline before you are told. Longer ignores brief outages.
Webhook
Optional URL that gets a JSON POST for each alert.
Sender address
Optional. Default skywire-alerts@this host, or the relay login.
Send through an SMTP relay
Without one, mail goes straight to the recipient's mail server on port 25, which many home connections block and large providers often refuse.
